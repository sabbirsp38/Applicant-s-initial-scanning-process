A plugin to collect and manage job applicant information and assign tasks.

== Description ==
Job Applicant Manager helps you collect and manage job applications through your WordPress site. Assign tasks to applicants and track their responses.

Features:
* Collect job applications through forms
* Assign tasks to applicants
* Track applicant responses
* Manage applications in admin dashboard

== Installation ==
1. Upload the plugin files to `/wp-content/plugins/job-applicant-manager`
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Use the shortcode [job_applicant_form] to display the application form

== Frequently Asked Questions ==
= How do I display the application form? =
Use the shortcode [job_applicant_form] in any post or page.
